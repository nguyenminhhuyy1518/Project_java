# Project_java
student management program
Ứng dụng quản lý sinh viên được xây dựng bằng Java Swing với mục đích học tập và thực hành lập trình Java Desktop Application.

---

## Giới thiệu

Dự án mô phỏng hệ thống quản lý sinh viên cơ bản giúp người dùng có thể thực hiện các thao tác quản lý thông tin sinh viên thông qua giao diện trực quan.

Dự án được thực hiện nhằm:
- Thực hành lập trình Java Swing
- Làm quen với mô hình MVC
- Quản lý dữ liệu bằng JTable
- Xử lý sự kiện trong Java
- Rèn luyện kỹ năng xây dựng ứng dụng desktop

---
